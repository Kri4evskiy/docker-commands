# Docker Команды

## Просмотр
* `docker ps -a` — показать все контейнеры (даже остановленные)
* `docker images` — показать все образы

## Запуск
* `docker run -d -it <image>` — запустить контейнер

### Флаги запуска (`docker run`):
* `-i` — интерактивный режим (оставляет открытым ввод STDIN)
* `-t` — выделение псевдотерминала (TTY)
* `-it` — запуск в интерактивном режиме с консолью (чтобы контейнер не завершался сразу)
* `-d` — запуск в фоновом режиме (detach)

## Удаление
* `docker rm <container_name/container_id>` — удалить конкретный контейнер
* `docker rmi <image_name/image_id>` — удалить конкретный образ
* `docker container prune` — удалить все остановленные контейнеры
* `docker image prune` — удалить все неиспользуемые образы
